A simple web page project for the **Theory of Computation** `INF05035` class about **Automata**. The project can be accessed [here](https://fabiobjr.github.io/nfa-converter/) or locally by following the instructions below.

## Description
The main goal was to develop an **algorithm** to convert a **NFA** (Non-Deterministic Finite Automaton) to a **DFA** (Deterministic Finite Automaton).<br>
Check algorithm: [nfa-converter/js/conversor.js](https://github.com/FabioBJr/nfa-converter/blob/main/js/conversor.js).

## Instructions
1. **Clone the repository:**
  ```bash
  git clone https://github.com/FabioBJr/nfa-converter.git
  ```
2. Install the **Live Server** extension for VSCode.
3. Click the "Go Live" button at the **bottom-right corner** of the **VSCode** screen.
